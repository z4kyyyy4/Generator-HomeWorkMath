# Generator HW
 
Расширение для VS Code, которое за пару секунд создаёт домашнее задание по математике: линейные или квадратные уравнения сразу с ответами. Задание и ответы сохраняются в разные файлы, поэтому ученику можно отправить задание без ответов.
 
## Возможности
 
- **Линейные уравнения** вида `ax + b = c` с целым корнем.
- **Квадратные уравнения** вида `ax² + bx + c = 0` с двумя разными целыми корнями. Иногда попадаются неполные: `x² − 9 = 0`, `x² + 5x = 0`.
- **От 1 до 50 уравнений** за один запуск, каждый раз новые числа.
- **Два файла**: `ДЗ.md` с заданием и `Ответы.md` с ответами под теми же номерами.
- **Запись как в тетради**: `x` вместо `1x`, `− 6` вместо `+ -6`, без нулевых членов, с настоящим знаком минуса.
## Установка
 
### Из файла .vsix
 
1. Соберите файл `generator-hw-0.0.1.vsix` (см. ниже) или получите его у автора.
2. В VS Code откройте панель расширений: `⌘⇧X` на macOS, `Ctrl+Shift+X` на Windows и Linux.
3. Нажмите `···` вверху панели → **Install from VSIX…** и выберите файл.
То же из терминала:
 
```bash
code --install-extension generator-hw-0.0.1.vsix
```
 
### Сборка .vsix из исходников
 
Нужны Node.js 18+ и Git.
 
```bash
git clone https://github.com/z4kyyyy4/generator-hw.git
cd generator-hw
npm install
npm install -g @vscode/vsce
vsce package
```
 
`vsce` (Visual Studio Code Extension Manager) — официальный инструмент для упаковки расширений. Перед упаковкой он сам компилирует TypeScript. В папке проекта появится `generator-hw-0.0.1.vsix`.
 
## Использование
 
1. Откройте в VS Code папку, куда сохранить задание: **File → Open Folder**.
2. Откройте палитру команд: `⌘⇧P` на macOS, `Ctrl+Shift+P` на Windows и Linux.
3. Выберите **Генератор ДЗ: Создать ДЗ по уравнениям**.
4. Выберите тип: **Линейные** или **Квадратные**.
5. Введите количество уравнений от 1 до 50 и нажмите Enter.
В папке появятся `ДЗ.md` и `Ответы.md`, задание сразу откроется в редакторе. Esc на любом шаге отменяет генерацию.
 
## Примеры
 
### Линейные уравнения, 5 штук
 
`ДЗ.md`:
 
```
# Линейные уравнения
 
1. 7x + 20 = 41
2. 3x − 20 = 10
3. 4x − 18 = −38
4. −6x − 17 = 13
5. −5x + 9 = −36
```
 
`Ответы.md`:
 
```
# Ответы
 
1. x = 3
2. x = 10
3. x = −5
4. x = −5
5. x = 9
```
 
### Квадратные уравнения, 4 штуки
 
`ДЗ.md`:
 
```
# Квадратные уравнения
 
1. x² − 6x + 5 = 0
2. 2x² − 10x + 12 = 0
3. x² − 9 = 0
4. 3x² + 3x − 216 = 0
```
 
`Ответы.md`:
 
```
# Ответы
 
1. x₁ = 1, x₂ = 5
2. x₁ = 2, x₂ = 3
3. x₁ = −3, x₂ = 3
4. x₁ = −9, x₂ = 8
```
 
## Как это работает
 
Уравнение строится **от ответа**: сначала выбирается корень, а коэффициенты вычисляются из него. Поэтому ответ всегда целый и известен заранее.
 
- **Линейное.** Выбираются корень `x` (от −10 до 10), `a` (от −9 до 9, кроме нуля) и `b` (от −20 до 20). Правая часть вычисляется: `c = a·x + b`. Например, `x = 3`, `a = 2`, `b = 5` дают `2x + 5 = 11`.
- **Квадратное.** Выбираются разные корни `x₁`, `x₂` (от −9 до 9) и множитель `k` (от 1 до 3). Уравнение получается раскрытием скобок `k(x − x₁)(x − x₂)`, то есть `a = k`, `b = −k(x₁ + x₂)`, `c = k·x₁·x₂`. Это теорема Виета в обратную сторону.
## Ограничения
 
- Должна быть открыта папка, иначе плагин покажет ошибку «Сначала откройте папку».
- Если открыто несколько папок, файлы сохраняются в первую.
- `ДЗ.md` и `Ответы.md` перезаписываются при каждом запуске. Чтобы сохранить старое задание, переименуйте файлы.
## Разработка
 
```bash
npm install
```
 
Откройте папку проекта в VS Code и нажмите **F5** (на MacBook **fn + F5**). Откроется окно **[Extension Development Host]** с подключённым плагином. После изменения кода сохраните файлы и перезапустите плагин зелёной стрелкой ⟳ на панели отладки.
 
| Файл | Что делает |
|---|---|
| `package.json` | манифест: объявляет команду |
| `src/extension.ts` | регистрирует команду, ведёт диалог, записывает файлы |
| `src/linear.ts` | генератор линейных уравнений |
| `src/quadratic.ts` | генератор квадратных уравнений |
| `src/format.ts` | запись уравнений по-школьному |
| `src/random.ts` | случайные целые числа |
