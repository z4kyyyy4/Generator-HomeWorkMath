# О плагине

**Generator HW** — расширение для VS Code, которое создаёт домашнее задание по математике: линейные или квадратные уравнения сразу с ответами.

Зачем: репетитору не нужно каждый раз вручную придумывать уравнения с «хорошими» корнями. Плагин делает это за пару секунд, и каждый раз с новыми числами.

## Что умеет

- линейные уравнения `ax + b = c` с целым корнем;
- квадратные уравнения `ax² + bx + c = 0` с двумя разными целыми корнями;
- от 1 до 50 уравнений за один запуск;
- задание и ответы сохраняет в разные файлы: `ДЗ.md` и `Ответы.md`.

## Как пользоваться

1. Открыть папку в VS Code: **File → Open Folder**.
2. Нажать `⌘⇧P` (Windows: `Ctrl+Shift+P`) и выбрать **Генератор ДЗ: Создать ДЗ по уравнениям**.
3. Выбрать тип уравнений: **Линейные** или **Квадратные**.
4. Ввести количество от 1 до 50.

В папке появятся два файла, задание сразу откроется.

## Пример

`ДЗ.md`:

```
# Квадратные уравнения

1. x² − 6x + 5 = 0
2. 2x² − 10x + 12 = 0
```

`Ответы.md`:

```
# Ответы

1. x₁ = 1, x₂ = 5
2. x₁ = 2, x₂ = 3
```
