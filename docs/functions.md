# Функции

## extension.ts

### `activate(context)`

Вызывается VS Code при запуске плагина. Регистрирует команду `generator-hw.generate` и кладёт её в `context.subscriptions`, чтобы VS Code сам убрал её при выключении плагина.

Функция, которая выполняется при вызове команды, объявлена `async`: диалоги ждут ответа пользователя через `await`. Шаги этой функции описаны в [architecture.md](architecture.md).

### `deactivate()`

Вызывается при выключении плагина. Освобождать нечего, поэтому функция пустая.

## linear.ts

### `linearEquation()`

Создаёт линейное уравнение `ax + b = c` с целым корнем. Возвращает объект `{ question, answer }`: условие и ответ.

Уравнение строится от ответа:

1. корень `x` — от −10 до 10;
2. `a` — от −9 до 9, но не 0 (цикл `while` выбирает заново, пока выпадает 0);
3. `b` — от −20 до 20;
4. правая часть вычисляется: `c = a·x + b`.

Пример: `x = 3`, `a = 2`, `b = 5` → `2x + 5 = 11`, ответ `x = 3`.

## quadratic.ts

### `quadraticEquation()`

Создаёт квадратное уравнение `ax² + bx + c = 0` с двумя разными целыми корнями. Возвращает `{ question, answer }`.

1. корни `x1` и `x2` — от −9 до 9, разные;
2. множитель `k` — от 1 до 3;
3. раскрываются скобки `k(x − x1)(x − x2)`:
   `a = k`, `b = −k(x1 + x2)`, `c = k·x1·x2` (теорема Виета в обратную сторону);
4. в ответе корни идут по возрастанию (`Math.min`, `Math.max`).

Пример: корни 2 и 3, `k = 2` → `2x² − 10x + 12 = 0`, ответ `x₁ = 2, x₂ = 3`.

## format.ts

### `formatPolynomial(terms)`

Записывает многочлен как в тетради. Принимает массив членов `{ coef, variable }`, где `variable` — `'x²'`, `'x'` или `''` для числа.

- нулевые члены пропускает;
- коэффициент 1 перед переменной не пишет: `x`, а не `1x`;
- между членами ставит ` + ` или ` − `;
- если все члены нулевые, возвращает `0`.

Пример: `[{coef: −4, variable: 'x'}, {coef: −6, variable: ''}]` → `−4x − 6`.

### `formatTerm(t, first)`

Вспомогательная функция для `formatPolynomial`, из других файлов недоступна. Записывает один член: знак, коэффициент, переменную. Если член первый (`first = true`), перед ним не ставится плюс, а минус пишется без пробелов.

### `formatNumber(n)`

Записывает число со знаком «−» вместо дефиса: `−7`. Используется для правой части линейного уравнения и для ответов.

## random.ts

### `randomInt(min, max)`

Возвращает случайное целое число от `min` до `max` включительно:

```ts
Math.floor(Math.random() * (max - min + 1)) + min
```

`Math.random()` даёт число от 0 до 1 (1 не включается). Его умножают на количество возможных чисел, отбрасывают дробную часть и сдвигают на `min`.
